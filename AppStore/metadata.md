**Description:**
Morse Tree teaches Morse code the way it is built: as a tree. Every letter is a path from the antenna. Go right for a dot, left for a dash, and read the path to get the code. Once you see the tree, you stop memorising tables and start understanding them.

LEARN ON THE TREE
• Tap any letter to hear it and watch its path light up
• Walk the whole tree letter by letter
• Hide the letters and test yourself on the shape alone
• Numbers and punctuation included

KEY YOUR WAY
• One key: tap for a dot, hold for a dash
• Two keys: separate dot and dash paddles
• On a Mac: left click for a dot, right click for a dash
• Adjustable speed (WPM), tone pitch and letter gap

QUIZZES THAT FOLLOW THE TREE
• Send or receive letters, numbers, words and Q codes
• Levels grow with the tree depth, from E and T to every letter
• A heat map shows exactly which letters need practice

PRACTISE REAL TEXT
• Type any text and hear it at correct Morse spacing
• Then key it yourself, letter by letter, with instant feedback

GLOSSARY FOR NEW OPERATORS
• Q codes like QRS (send slower), QTH, QSL and QRZ
• Prosigns such as AR, SK, BT and KN
• Common abbreviations: 73, 88, TNX, PSE, AGN, FB and more
• RST signal reports and a sample first contact
• Tap any entry to hear it

RADIO MODE
• Send Morse or push-to-talk voice to nearby phones running Morse Tree over Bluetooth
• No internet, no accounts, no servers

PRIVATE BY DESIGN
No accounts, no ads, no tracking, no data collection. Your progress stays on your device.

**What's New (1.1):**
New in the Quiz tab:
• QSO practice: a station calls you. Listen, then work out and key the right reply, step by step through a real contact, from CQ to 73. Every contact has a new callsign, name, city and report.
• PRO mode: no tree hints, every letter and digit mixed, real letter spacing, and a characters-per-minute score. In QSO, PRO hides the other station's text so you copy by ear.

**App Review notes:**
Morse Tree works fully offline and needs no account. Radio mode (Radio tab) sends Morse and push-to-talk voice to other devices running Morse Tree over Bluetooth, so testing it needs two devices; all other features work on one device. The microphone is used only while the push-to-talk button is held, and Bluetooth only while the radio is turned on. On Mac, Settings › Mouse keys enables left click = dot, right click = dash.
